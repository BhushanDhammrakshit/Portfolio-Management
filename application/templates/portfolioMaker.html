How to download your holdings CSV
Zerodha (Kite)
  1. Log in to kite.zerodha.com
  2. Go to Portfolio → Holdings
  3. Click the download icon at the top-right of the holdings table
  4. Select "Download as CSV"
  5. Upload the downloaded .csv file here
Angel One
  1. Log in to angelone.in or open the Angel One app
  2. Go to Portfolio → Holdings
  3. Tap the three-dot menu → "Download"
  4. Choose CSV format
  5. Upload the file here
Groww
  1. Log in to groww.in (web only)
  2. Go to Stocks → Holdings
  3. Click "Download Report" at the top of the page
  4. Select Holdings Report and date range → Download as CSV
  5. Upload the file here
Upstox
  1. Log in to pro.upstox.com
  2. Go to Portfolio → Holdings
  3. Click the export/download button
  4. Download as CSV
  5. Upload the file here
Fyers
  1. Log in to trade.fyers.in
  2. Go to Portfolio → Holdings
  3. Click the download icon at the top-right corner
  4. Select CSV format
  5. Upload the file here
5paisa
  1. Log in to trade.5paisa.com
  2. Go to My Portfolio → Holdings
  3. Click "Export" or the download icon
  4. Download as CSV/Excel (save as .csv if Excel)
  5. Upload the file here
Dhan
  1. Log in to web.dhan.co
  2. Go to Portfolio → Holdings
  3. Click "Download" at the top of the holdings list
  4. Select CSV
  5. Upload the file here
CDSL / NSDL (CAS Statement)
  1. Visit cdslindia.com/cas or nsdl.co.in/cas
  2. Download your Consolidated Account Statement
  3. Open the PDF, copy the holdings table into Excel/Google Sheets
  4. Save as .csv with columns: Stock Name, ISIN, Quantity, Avg Price
  5. Upload the file here
